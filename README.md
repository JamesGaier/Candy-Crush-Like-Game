# Candy Crush like Game

I am going try to re-create an IOS game that I remember that was like Candy Crush.  The main difference was that in the other game there were monsters that could destroy blocks. Also the items were not candy they were stones like Bejewled.

## Goals

1. I make a prototype/clone of Candy Crush in pygame to understand how to build it
1. I port that prototype into rust
1. I iterate on it by making it more similar to what I remember on the iphone game


I ideally want to do this with old games I remember that I can no longer access like this one "Who Wants to be A Millionaire" game on the IPod Classic or this other ipod classic game that was like breakout, or this other one that was like circular breakout and 3d...
